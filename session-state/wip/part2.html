1 · Before we begin

The spine so far: P01 pinned the claim, P02 built the table, P03 attacked it with hostile cases, P04 paid for corners, P05 dressed every object in its uniform, P06 composed stuck objects inside identities, P07 built the objects nobody handed us, P08 divided by the twins, P09 found the quantity nothing can change, P10 forced collisions by counting, P11 exploded the opposite of the claim, P12 named the wall the explosion leaned on, and P13 convicted whole families by manufacturing ever-smaller criminals. The ladder arrives here in order, and it arrives carrying two tools that this page will lean on hard: P10 taught that sameness of size means matchability by rows — two sets are the same size exactly when you can pair them off, one row each — and P11 taught the frame: assume the thing you doubt, and run the machine until it breaks.

Here is the tension this page resolves. The good news: the two halves of the coming argument are already yours. The row-matching definition of size is P10's, and the exhaustive list is a claim you now know how to doubt — assume it, said P11, and see what it commits you to. The bad news, paid up front: the claim type is brand new. Every impossibility so far convicted a kind of object — no fraction equals \(\sqrt 2\), no lattice triangle is equilateral. The fourteenth move convicts a list: the census taker's claim that his rows cover everything there is. No census can check that claim — the rows run forever, and a finite search of an infinite list seals nothing, exactly as P02 taught about detectors. P13's engine is idle here too: lists do not shrink, so there is no smaller criminal to manufacture. And yet the claim dies in one construction — not by finding a flaw in any particular row, but by building, from the list's own diagonal, the one object no list of that shape can contain. The refutation is constructive inside a contradiction: P11's frame, P07's built object, and P10's row-matching all working one shift together.

2 · Meet the problem

Here is a claim you can hold in your hands. A friend — call him the census taker — announces that every number between \(0\) and \(1\) is on his list, and shows you the first eight rows, ten digits each:

rowdigitswhat it is
13333333333\(1/3\)
21414141414\(14/99\)
37182818284\(e - 2\)
41415926535\(\pi - 3\)
55000000000\(1/2\)
66666666666\(2/3\)
78660254037\(\sqrt{3}/2\)
84142135623\(\sqrt{2} - 1\)

Do not check his arithmetic row by row — every row can be perfectly honest and the claim can still be doomed. Instead, run the digit-flip machine. Walk down the diagonal: the digit of row \(1\) in position \(1\), of row \(2\) in position \(2\), of row \(3\) in position \(3\), and so on. The diagonal reads \(3, 4, 8, 5, 0, 6, 4, 6\) — one digit from each row, each from its own position. Now build the shadow number, one digit at a time, with this rule: at position \(n\), write \(1\) if row \(n\)'s \(n\)-th digit is anything other than \(1\); write \(2\) if it is \(1\). The diagonal never shows a \(1\) — so the shadow's first eight digits are all \(1\)'s:

\[0.\underline{1}\,1\,1\,1\,1\,1\,1\,1\,\ldots\]

Check the machine's work, row by row. Against row \(1\): the shadow's first digit is \(1\), the row's first digit is \(3\) — different, so the shadow is not \(1/3\). Against row \(2\): second digit \(1\) versus the row's \(4\) — not \(14/99\). Row \(3\): third digit \(1\) versus \(8\) — not \(e - 2\). Row \(4\): fourth digit \(1\) versus \(5\) — not \(\pi - 3\). Row \(5\): \(1\) versus \(0\) — not \(1/2\). Row \(6\): \(1\) versus \(6\) — not \(2/3\). Row \(7\): \(1\) versus \(4\) — not \(\sqrt{3}/2\). Row \(8\): \(1\) versus \(6\) — not \(\sqrt{2} - 1\). Eight rows, eight convictions, and not one of them took more than a glance at a single digit.

Now the trap closes — on the list, not on any row. Nothing stops at row \(8\). Row \(9\) has a ninth digit, and the rule gives the shadow its ninth digit against it; row \(10\) its tenth; every row the census taker ever writes gets exactly one position to answer for, and the rule differs there by construction. The shadow is nowhere on the list: it cannot be row \(1\) (they differ in position \(1\)), cannot be row \(2\) (they differ in position \(2\)), cannot be row \(n\) for any \(n\) at all — and a list is nothing but its rows. The census taker never had a chance; the claim "every number is on my list" died the moment the list took its shape, because the shadow is a number between \(0\) and \(1\) too — the construction stayed inside the target set, which §5's second exhibit shows is not a detail but a demand.
