Exercise 1 (●○○). (a) Rebuild \S2's certificate by hand: evaluate both sides of \((n-1)n(n+1)(n+2)+1 = (n^2+n-1)^2\) at \(n = -1, 0, 1, 2, 3\), and confirm the five agreements. Then run the substitution proof: set \(m = n^2 + n\) and watch both sides collapse to the same short expression. (b) Confirm the boundary from the other side: evaluate the witness \(x(x-1)(x-2)(x-3)\) at \(x = 0, 1, 2, 3\), then at \(x = 4\). (c) Generalize the witness: for any \(d\) chosen test points, exhibit a nonzero polynomial of degree \(d\) that vanishes at every one of them — and say in one sentence why this does not contradict the certificate theorem.

Hint

(a) All five left-hand values are small — the \(n = 2\) row is the first one that does not give \(1\). (b) Multiply the four factors at \(x = 4\). (c) The product of \((x - t)\) over the test points \(t\) is your friend; then count the witness's degree against the certificate's required count.

Worked

(a) \(n = -1\): \((-2)(-1)(0)(1) + 1 = 1\) against \((1 - 1 - 1)^2 = 1\). \(n = 0\): \(1\) against \((0 + 0 - 1)^2 = 1\). \(n = 1\): \(1\) against \(1\). \(n = 2\): \(25\) against \((4 + 2 - 1)^2 = 25\). \(n = 3\): \(121\) against \((9 + 3 - 1)^2 = 121\). Five agreements for a degree-4 difference — one more than the budget, identity certified. The substitution: \(m = n^2 + n\) makes the left side \((n^2 + n - 2)(n^2 + n) + 1 = (m - 2)m + 1 = m^2 - 2m + 1 = (m - 1)^2\), and the right side is \((m - 1)^2\) outright — both sides the same object in canonical form, which is P05's move doing what it does best: the two-line proof exists, and the certificate is the machine-check behind it. (b) At \(x = 0, 1, 2, 3\) some factor is zero, so the witness vanishes — four agreements with the zero polynomial. At \(x = 4\): \(4 \cdot 3 \cdot 2 \cdot 1 = 24 \ne 0\) — the witness is not zero, and no four-point test could ever have told. (c) Given test points \(t_1, \ldots, t_d\), take \((x - t_1)(x - t_2) \cdots (x - t_d)\): nonzero, degree exactly \(d\), vanishing at all \(d\) points. This does not contradict the certificate theorem because the theorem never promised \(d\) points would certify anything — it promised \(d + 1\) would, and the witness demonstrates the promise is exact: a degree-\(d\) difference can agree with zero at every point of a \(d\)-point test and still be a difference.

Exercise 2 (●●○). (a) Verify Example 2's four certificate sums by hand: at \(m = 0, 1, 2, 3\), confirm that both sides of \(\binom{m+4}{3} = 4 + 6m + 4\binom{m}{2} + \binom{m}{3}\) give \(4, 10, 20, 35\). (b) Sit in P01's chair: the certificate tested \(m\) and never \(n\). Explain exactly why — what was the claim as pinned, and what would have changed had the claim been the two-variable version? (c) Price the boundary: exhibit a nonzero polynomial of degree \(3\) that agrees with the zero difference at \(m = 0, 1, 2\), and say why this kills any three-point test of a cubic.

Hint

(a) \(\binom{m}{2} = \frac{m(m-1)}{2}\), \(\binom{m}{3} = \frac{m(m-1)(m-2)}{6}\); evaluate the right side's four terms separately first. (b) Which variables does the pinned claim actually mention? What degree does the two-variable version have, in each variable — and what test set does Example 2's second half use for it? (c) Build a cubic that vanishes at the three test points, then evaluate it one step to the right.

Worked

(a) \(m = 0\): \(\binom{4}{3} = 4\) against \(4 + 0 + 0 + 0 = 4\). \(m = 1\): \(\binom{5}{3} = 10\) against \(4 + 6 + 0 + 0 = 10\). \(m = 2\): \(\binom{6}{3} = 20\) against \(4 + 12 + 4 \cdot 1 + 0 = 20\). \(m = 3\): \(\binom{7}{3} = 35\) against \(4 + 18 + 4 \cdot 3 + 1 = 35\). Four agreements for a degree-3 difference: certified, exactly at price. (b) The claim as pinned is an identity in the single variable \(m\) — the fixed \(4\) is part of the claim's shape (it is the \(n = 4\) case of the Vandermonde convolution, substituted before testing), so there is no \(n\) in the claim and none to test: one variable, degree \(3\), four points, done. The trap the question guards against: the two-variable convolution \(\binom{m+n}{3} = \sum_k \binom{m}{k}\binom{n}{3-k}\) is a different claim — degree \(3\) in each of two variables — and it needs Example 2's \(4 \times 4\) grid, sixteen checks, not four. Testing the one-variable claim does not certify the two-variable one; conflating them is the P01 error of proving something other than what was asked. (c) \(m(m-1)(m-2)\): degree \(3\), zero at \(m = 0, 1, 2\), and \(6\) at \(m = 3\). A nonzero difference could pass any three-point test of a cubic — so the certificate's count is exact, not padded: \(d + 1\) or nothing.
