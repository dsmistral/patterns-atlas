3 · Name the move

§2 met the problem in its friendliest clothes: a toy, a census, an average that worked and then went quiet. The move, named:

Pattern P36 — Count with characters. When a count must respect symmetry — objects counted up to a group of transformations — do not list orbits and do not stop at one average: (1) realize the count as a trace: make the group act on the space of configurations, a vector space; each element \(g\) acts by a matrix, and its character \(\chi(g)\) — the trace of that matrix — is a count: for a permutation action, the number of configurations \(g\) freezes, computable as \(k^{\text{cycles}(g)}\) with no matrices anywhere — P01's discipline pins the group, the set, and the action before any counting; (2) tabulate the character: one row of numbers per conjugacy class, each number counted — fixed points, cycles, frozen configurations; (3) read the answers as inner products: \(\langle \chi, \psi \rangle = \frac{1}{|G|} \sum_{g \in G} \chi(g)\overline{\psi(g)}\) — the orbit count is \(\langle \chi_{\mathrm{config}}, \mathbf{1} \rangle\) (the average of P08, now wearing its true name), the multiplicity of each symmetry wave is \(\langle \chi, \psi \rangle\) against the wave's row, and every answer must come out a whole number — the free gate that catches slips. One table, computed once, answers the whole family.

Or, in words: when the asker wants a count that ignores symmetry, do not count harder — hand the symmetry a character sheet, one number per breed of motion, and let the table do the arithmetic. Every question in the family — how many, how many of each weight, how many waves of each kind — becomes a single row-times-column product.

The move applies when three keys line up, and each key names its own jam-mode:

Key 1 — the symmetry is a known, finite group action. "Up to rotation" must mean a specific group acting on a specific set, pinned before counting — the class census of §2 (five breeds, sizes \(1, 6, 3, 8, 6\), summing to 24) is the pin. Jam-mode: the symmetry is continuous or infinite — "up to arbitrary rotation", "up to translation" — and the sum over group elements becomes an integral over a group manifold; the honest move exists (the Haar average, the representation theory of compact groups) but it is another ladder, cited below as a door and built nowhere on this page. The jam returns to P01 and P05: pin the transformation group first; "up to symmetry" that has not been pinned is not a problem yet.

Key 2 — the question is linear in the action. Orbit counts, multiplicities, invariant dimensions, and weighted inventories all read off the character because they are all dimensions of subspaces built from the action — sums of irreducible waves. Jam-mode: the question is nonlinear in the group's behavior — "how many orbits have trivial stabilizer", "how many objects are fixed by exactly one rotation" — and the character, which only sees each element's trace, cannot separate them; those questions need inversion over the lattice of subgroups (the Burnside ring, a door §6 points at). The character is a ledger of averages; questions about deviations from the average must go back to the census, or to the harder bookkeeping.

Key 3 — the ground characteristic does not divide the group order. The whole ledger — the split into waves, the inner-product extraction, the integrality gate — rests on Maschke's license: over a field whose characteristic does not divide \(|G|\), every action splits cleanly into irreducible waves. Over the reals and complexes this is free. Jam-mode: characteristic \(p\) dividing \(|G|\) — the split fails, modules refuse to decompose, and the table stops answering; Exhibit B builds the smallest such failure by machine. The key is invisible in school arithmetic and load-bearing exactly there where it is invisible, which is why it is a key and not a footnote.

Box P36.A — the machine, in three obligations. Every instance of the pattern — the cube of §2, the triangle of Example 2, the necklace of Example 3 — owes the same three duties, all checkable at census scale:

1 · The action is pinned by a class census. The group's elements are sorted into conjugacy classes with sizes and cycle shapes, and the sizes must sum to the group order — the cube's \(1 + 6 + 3 + 8 + 6 = 24\), the triangle's \(1 + 3 + 2 = 6\). The receipt: every census below is generated by machine (the 24 rotation matrices built from two generators and closed; the six motions of the triangle listed by hand and checked), not copied from a book. A miscounted class poisons every inner product downstream, and the sum-check is the cheapest detector.

2 · The character is counted, not multiplied. For a permutation action the trace equals the count of fixed points — the diagonal of a permutation matrix is exactly its fixed set — and for configuration spaces the trace is cycles-to-the-\(k\): \(\chi_{\mathrm{config}}(g) = k^{c(g)}\). The receipt: every character value on this page was read off a cycle census and cross-checked against the trace of an actual matrix action on the smallest case, where the two computations must agree exactly. Characters computed by matrix multiplication are a right, not an obligation; the counting route is faster, safer, and — for the permutation actions this page counts — exact.

3 · The inner products come out whole, or the machine is wrong. Multiplicities are dimensions; \(\langle \chi, \chi \rangle = \sum_i m_i^2\) is a sum of squares; every extracted count must be a nonnegative integer. The receipt: the integrality gate runs on every inner product below, and a gate like that earns its keep: a fractional multiplicity is never "almost right"; it is a receipt that some class was miscounted, and the count stops until the class is found.

Box P36.B — where the move appears. The birth certificate — Frobenius, 1896, computing characters to factor a determinant (Dedekind's group determinant problem: a counting question about factorizations, answered by traces), the entire theory invented to count. The first triumph — Burnside's 1904 theorem that groups of order \(p^\alpha q^\beta\) are solvable, proved not by building the groups but by counting their irreducible characters, arithmetic on a table settling a question about all groups of a family. The license — Maschke 1899, the decomposition theorem that makes the ledger legal. The industry — Redfield's 1927 group-reduced distributions and Pólya's 1937 enumeration theorem (Acta Mathematica 68): the cycle index, the chemist's isomer counter, is a character in work clothes — and Pólya's theorem counts benzene rings and necklaces with the same line of algebra. The frontier — the Monster's character table, 194 irreducible rows computed before the group itself was constructed, and the Conway–Norton moonshine conjectures (1979) reading dimensions out of it that nobody could explain for a generation. The signature in the wild: any count qualified by "up to" — up to rotation, up to relabeling, up to symmetry — is a character count wearing its coat collar up; ask for the table before brute force, because the table is reusable and the census is not.
