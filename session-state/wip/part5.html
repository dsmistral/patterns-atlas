Example 2 · The reals refuse — and the rationals accept

Moves used: P05 choosing the safe costume for the digits · P11 assuming the enumeration exists · P02 reading the rationals' list as a growing table · P14 walking the diagonal.

Now the encounter's argument, with its seams shown and sewn. Suppose — P11's frame — that the reals between \(0\) and \(1\) are enumerable: some list \(r_1, r_2, r_3, \ldots\) contains every one of them. Write each row in decimal form. Build the shadow with the \(1\)-or-\(2\) rule:

\[s_n = \begin{cases} 1 & \text{if row } n\text{'s } n\text{-th digit is not } 1, \\ 2 & \text{if row } n\text{'s } n\text{-th digit is } 1. \end{cases}\]

Then \(s = 0.s_1 s_2 s_3 \ldots\) differs from \(r_n\) in position \(n\), for every \(n\). The one delicate point is what "differs" means for digit strings, and this is where P05's discipline pays. Some numbers wear two decimal costumes: \(0.5000\ldots\) and \(0.4999\ldots\) are the same number in two spellings, and in general the two-costume numbers are exactly the ones whose costume ends in all zeros or all nines. A hasty rule — "add \(1\) to each diagonal digit, mod \(10\)" — can produce a shadow that collides with a row through the back door of costume: a shadow ending in all nines is some terminating number that may well be sitting on the list. The \(1\)-or-\(2\) rule shuts that door. A string of \(1\)'s and \(2\)'s cannot end in all zeros and cannot end in all nines, so it wears exactly one costume; and since the shadow and row \(n\) differ at position \(n\) while neither can be the other's costume-twin (the twin would have to supply the \(0\)'s or \(9\)'s the shadow never writes), the difference of digits is a difference of numbers. The demand of genuine difference, cleared.

So \(s\) is a real in \([0,1)\), and \(s\) is not row \(n\) for any \(n\) — the enumeration missed it, and it was assumed to miss nothing. The reals cannot be enumerated. Every "complete list of the reals" is missing at least one number, and the digit-flip machine will name it from the list's own geometry. (§5's first exhibit shows the collision a careless rule invites.)

Here is the constructive surprise, and it is the flip side of the same coin: the rational numbers between \(0\) and \(1\) are perfectly listable. The denominator sweep does it. List \(0\) first as \(0/1\); then run through denominators \(q = 2, 3, 4, \ldots\), and inside each block list the fractions \(p/q\) with \(1 \le p < q\) and \(\gcd(p, q) = 1\), in increasing order of \(p\). The list begins:

\[0,\; \tfrac{1}{2},\; \tfrac{1}{3},\; \tfrac{2}{3},\; \tfrac{1}{4},\; \tfrac{3}{4},\; \tfrac{1}{5},\; \tfrac{2}{5},\; \tfrac{3}{5},\; \tfrac{4}{5},\; \tfrac{1}{6},\; \tfrac{5}{6},\; \tfrac{1}{7},\; \tfrac{2}{7},\; \tfrac{3}{7},\; \ldots\]

Every rational in \([0,1)\) appears, and none appears twice: a rational has exactly one reduced form — its canonical costume, as P05 would say — and its reduced form has exactly one denominator, so it shows up in exactly one block, in that block's order. This is a genuine enumeration, with a row number for every rational: \(1/2\) sits in row \(2\), \(2/3\) in row \(4\), \(3/7\) in row \(15\) — count the blocks yourself, P02's growing table made precise. So "infinite" does not mean "unlistable": some infinite collections accept row numbers, and the counting numbers' own rows pair off with the rationals between \(0\) and \(1\), one row each, nothing left over.

What happens if you run the digit-flip machine on the rational sweep anyway? It still works: the shadow of the sweep list differs from every row, so it is a real number that is not any rational in \([0,1)\). And that is exactly as it should be — the shadow of the rational list is irrational. No contradiction, because the flip left the domain: the sweep only ever claimed to exhaust the rationals, and the object it missed was never owed a row (the membership demand, failed — on purpose). The lesson cuts both ways, and §5 makes it an exhibit: the diagonal machine proves incompleteness of lists, and when the domain is genuinely listable, the machine's "miss" is a certificate of the domain's outside, not of the list's failure.

One corollary, and it is a jewel. The reals in \([0,1)\) cannot be enumerated; the rationals in \([0,1)\) can. If the irrationals in \([0,1)\) could also be enumerated, then interleaving the two lists — rational row \(n\) in row \(2n\), irrational row \(n\) in row \(2n - 1\) — would enumerate the whole interval, which cannot be done. So the irrationals are uncountable too. Irrational numbers exist in overwhelming abundance — and this proof never exhibits a single one. No page of arithmetic manufactures a candidate the way P13 manufactured \(\sqrt 2\)'s decimal; instead, the counting itself guarantees the species. Existence without exhibition, delivered by the shape of two lists — and the algebraic-number version of the same jewel is Exercise 5.
