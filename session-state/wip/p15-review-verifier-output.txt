============================================

Engine: p15-review-verifier.js, an independent second engine sharing no code
with p15-lab.js. 15 substantive checks, each recomputing the mathematics from
first principles (Math.sin/tan; exact integer arithmetic where the page claims
integers; half-of-last-digit tolerances on printed roundings) before testing
the assembled page bytes.
