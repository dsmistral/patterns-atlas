4 · The move at work

Three worked examples, one per appearance in the catalogue. The first takes the move to its natural home — sets — where no decimals are needed and the argument is three lines long. The second returns to the reals with the rigor the encounter skipped, and pairs it with the constructive surprise that the rationals do submit to a list. The third runs the flip on machines, and shows why no program can predict all programs — including itself.

Example 1 · No function reaches every subset (Cantor's theorem)

Moves used: P01 pinning "bigger" as "no pairing exists" · P11 assuming the pairing exists · P07 building the subset nobody supplied · P14 flipping membership along the diagonal.

The census taker's digits were costume; the skeleton underneath is this. Let \(S\) be any set, and let \(\mathcal{P}(S)\) be the collection of all subsets of \(S\) — the power set. The claim to kill: that some function \(f : S \to \mathcal{P}(S)\) reaches every subset, i.e. that the subsets of \(S\) are no more numerous than the elements of \(S\). Read that as a list: row \(x\) of \(f\)'s table is the subset \(f(x)\), one row per element \(x \in S\), and the claim is that every subset appears in some row.

Build the shadow. In the digit table, row \(n\) exposed a digit at position \(n\); here row \(x\) exposes a perfectly crisp yes-or-no fact about the element \(x\): is \(x\) a member of \(f(x)\)? That yes-or-no is the coordinate, and it is yours to disagree with. Define

\[D \;=\; \{\, x \in S : x \notin f(x) \,\}.\]

One line: flip the membership on the diagonal. \(D\) is a subset of \(S\) — it is built from elements of \(S\) — so \(D\) lives in \(\mathcal{P}(S)\), the very collection the list claims to exhaust (the membership demand, cleared). Now compare \(D\) against the rows. Row \(x\) and \(D\) disagree at the element \(x\), by construction:

  • if \(x \in f(x)\), then \(x \notin D\) — the two subsets differ at \(x\);
  • if \(x \notin f(x)\), then \(x \in D\) — again they differ at \(x\).

Every row \(x\) disagrees with \(D\) at its own index. So \(D\) is not row \(x\), for any \(x\): the function missed a subset. And \(f\) was arbitrary — nothing in the construction used any special property of it, so no function from \(S\) onto \(\mathcal{P}(S)\) exists. The collection of subsets is strictly bigger than the set: \(|S| < |\mathcal{P}(S)|\).

Concrete, at a size you can hold: take \(S = \{1, 2, 3\}\), and the particular function

\[f(1) = \{2,3\}, \qquad f(2) = \{2\}, \qquad f(3) = \{1,3\}.\]

The diagonal question runs down the elements: is \(1 \in f(1) = \{2,3\}\)? No — so \(1 \in D\). Is \(2 \in f(2) = \{2\}\)? Yes — so \(2 \notin D\). Is \(3 \in f(3) = \{1,3\}\)? Yes — so \(3 \notin D\). The shadow subset is \(D = \{1\}\), and the three rows are \(\{2,3\}\), \(\{2\}\), \(\{1,3\}\) — \(\{1\}\) is on none of them. The function reached three subsets out of eight; its miss was manufactured, not found.

Two consequences deserve their own sentences. First, a set of (n) elements has (2^n) subsets — eight for a three-element set, sixteen for a four-element one — each element choosing in or out, which already outgrows \(n\) by P10's count. Second — and this is the ceilingless part — the theorem never needed \(S\) to be finite. Run it on \(S = \mathbb{N}\): the subsets of the counting numbers cannot be enumerated, not by any list, ever. Run it again on \(\mathcal{P}(\mathbb{N})\): bigger still. The ladder of sizes has no top rung: given any infinity, the power-set move builds a bigger one. Before this page, "bigger" for infinite collections had no meaning — P10's row-matching gives it one, and P14's flip immediately finds a rung above every rung.
