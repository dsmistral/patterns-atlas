RUN HISTORY (honest):
- The verifier's headline find: F17/V25 DISAGREED on the page fingerprint.
  The battery's original hash multiplied in float64 past 2^53, so its
  "fingerprint" 0xd4d2f408 was a rounding artifact, not the true FNV-1a.
  Both sides were rebuilt on Math.imul (exact 32-bit multiply) and validated
  against the standard vectors ("" -> 811c9dc5, "a" -> e40c292c,
  "foobar" -> bf9cf968); the true fingerprint is 0x046465e4, now pinned on
  both sides, and the whole battery was re-run after the fix. The page
  itself was never wrong — the lab's hash check was.
- Three verifier-side check bugs were found and fixed before any verdict
  was accepted: (1) V7/V8's cycle arrays put 0 where n mod 4 = 0 demands
  1; (2) V10's first engine kept the 8x8 board in a single JS bitmask —
  bitwise operators are 32-bit, so cells 32..63 wrapped and the engine
  returned 0 — rebuilt on split lo/hi masks and then agreeing with the
  battery (30,355 and 13,779); (3) V16 compared factor splices without
  sorting the concatenation first.
- After the fixes: all 26 fresh checks PASS, and all 16 poisoned
  injections are correctly REJECTED — no gate is blind to any mutation
  class it was built to catch.
