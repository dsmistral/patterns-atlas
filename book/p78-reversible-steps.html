Tier 2 · Canon Foundations

P78 · Make every step reversible

Turn leaky one-way implications (\(\implies\)) into airtight logical equivalences (\(\iff\)) by carrying explicit domain and sign guards alongside your algebra — banishing ghost roots, lost solutions, and backward-proof fallacies.

Prerequisites: P03 · Stress-test with special cases, P77 · Work backwards

On-ramp 1 — One-way implication (\(\implies\)) vs. Logical equivalence (\(\iff\)). When you solve an equation by transforming \(E_0(x) \to E_1(x) \to \cdots \to E_k(x)\), two opposite leaks can corrupt the solution set:

  • Information loss (\(\implies\) only, creating ghost/extraneous roots): Squaring both sides (\(A = B \implies A^2 = B^2\)) or multiplying by \(x - 2\) enlarges the solution set. Solutions of the final equation may fail the original equation!
  • Root loss (\(\impliedby\) only, dropping valid roots): Dividing both sides of \(x(x - 3) = 2(x - 3)\) by \(x - 3\) silently throws away the valid root \(x = 3\)!

When every step is an if-and-only-if (\(\iff\)), the solution set of \(E_k(x)\) is guaranteed to be identical to the solution set of \(E_0(x)\).

On-ramp 2 — How a guard condition turns \(\implies\) into \(\iff\). Almost every non-reversible algebraic step becomes \(100\%\) reversible the moment you attach a simple side condition (a guard):

  • Squaring a radical: \(\sqrt{A} = B \;\Longleftrightarrow\; \bigl(B \ge 0 \;\text{ and }\; A = B^2\bigr)\).
  • Canceling a common factor: \(E \cdot A = E \cdot B \;\Longleftrightarrow\; \bigl(E = 0 \;\text{ or }\; A = B\bigr)\).
  • Clearing a denominator: \(\frac{A}{D} = C \;\Longleftrightarrow\; \bigl(D \neq 0 \;\text{ and }\; A = C \cdot D\bigr)\).

1 · Before we begin

In P03 · Stress-test with special cases, we learned to test degenerate boundary cases (like \(D = 0\) or negative inputs) where naive formulas break down. And in P77 · Work backwards, we saw that discovering an inequality or construction by working backwards from the target \(S_{\text{goal}}\) to a known truth \(C_0\) is a valid proof only if every step can be reversed.

Make every step reversible (P78) is the discipline that makes P77 and all of algebraic manipulation airtight: instead of doing sloppy one-way algebra and hoping to catch errors at the end, you package the exact domain/sign guard into each step so that every arrow is a verified \(\iff\).

2 · Meet the problem: the ghost root at \(x = -1\) and the mediant inequality

Let us inspect two classic situations — one where an unguarded step invents a false solution, and one where guarded \(\iff\) steps prove an inequality in a single pass.

Encounter A · Where did the ghost root \(x = -1\) come from?

Solve the real radical equation

\[ \sqrt{2x + 3} \;=\; x \qquad (x \in \mathbb{R}). \]

A hasty solution squares both sides without a guard:

\[ \sqrt{2x + 3} = x \;\;\implies\;\; 2x + 3 = x^2 \;\;\implies\;\; x^2 - 2x - 3 = 0 \;\;\implies\;\; (x - 3)(x + 1) = 0 \;\;\implies\;\; x \in \{-1,\; 3\}. \]

Yet when you plug \(x = -1\) back into \(\sqrt{2x + 3} = x\), the left-hand side is \(\sqrt{2(-1) + 3} = \sqrt{1} = +1\) (since \(\sqrt{\cdot}\) denotes the principal nonnegative square root!), while the right-hand side is \(-1\): \(+1 \neq -1\)! Why did \(x = -1\) sneak in? Because squaring erased the minus sign in \(+1 = -1\), merging the upper half-parabola \(y = +\sqrt{2x+3}\) with the lower half-parabola \(y = -\sqrt{2x+3}\) (Fig P78.1)!

Now solve the exact same equation using a guarded equivalence (P78): since \(\sqrt{A} \ge 0\) automatically forces \(B \ge 0\) and \(A = B^2 \ge 0\),

\[ \sqrt{2x + 3} = x \quad\Longleftrightarrow\quad \Bigl(x \ge 0 \;\;\text{and}\;\; 2x + 3 = x^2\Bigr) \quad\Longleftrightarrow\quad \Bigl(x \ge 0 \;\;\text{and}\;\; x \in \{-1, 3\}\Bigr) \quad\Longleftrightarrow\quad x = 3. \]

Carrying the guard \(x \ge 0\) filters out \(-1\) automatically — even if the equation contains parameters where you cannot plug in numerical roots at the end!

Encounter B · Proving a fraction inequality in a single \(\iff\) chain

Suppose \(0 < b < a\) (so \(\frac{b}{a} < 1\) is a proper positive fraction) and \(k > 0\). Prove that adding \(k\) to both numerator and denominator pulls the fraction strictly closer to \(1\):

\[ \frac{b}{a} \;<\; \frac{b + k}{a + k}. \]

Because \(a > 0\), \(k > 0\), and \(a + k > 0\) are all strictly positive, every step below is an unconditional equivalence (\(\iff\)):

\[ \begin{aligned} \frac{b}{a} \;<\; \frac{b + k}{a + k} &\quad\Longleftrightarrow\quad b(a + k) \;<\; a(b + k) &&\bigl(\text{multiplying by } a(a+k) > 0 \text{ is reversible!}\bigr) \\ &\quad\Longleftrightarrow\quad ab + bk \;<\; ab + ak &&\bigl(\text{distributing is an identity}\bigr) \\ &\quad\Longleftrightarrow\quad bk \;<\; ak &&\bigl(\text{subtracting } ab \text{ is reversible!}\bigr) \\ &\quad\Longleftrightarrow\quad b \;<\; a &&\bigl(\text{dividing by } k > 0 \text{ is reversible!}\bigr). \end{aligned} \]

Since the bottom line \(b < a\) is given as true, and every step is \(\iff\), the top line is proved immediately!

3 · Name the move

Box P78 · The Reversible Steps Move

Whenever you transform an equation, inequality, or combinatorial set \(S_0 \to S_1 \to \cdots \to S_m\), audit each step so that it is an exact logical equivalence (\(\iff\)) (or an explicit bijection \(\Phi : X \leftrightarrow Y\) with verified inverse \(\Psi = \Phi^{-1}\)):

\[ P(x) \quad\Longleftrightarrow\quad \bigl(G(x) \;\;\text{and}\;\; Q(x)\bigr), \]

where \(G(x)\) records any positivity, non-vanishing, or domain conditions required to invert the step \(P(x) \mapsto Q(x)\).

Box P78.A · The Four Verification Obligations of Reversible Steps

  1. Non-Vanishing & Sign Audit on Multipliers \(E(x)\): Before multiplying or dividing an equation by \(E(x)\), check whether \(E(x) = 0\) is possible (if so, split off \(E(x) = 0\) as an OR branch). Before multiplying an inequality by \(E(x)\), prove \(E(x) > 0\) (or split into \(E(x) > 0\) and \(E(x) < 0\)).
  2. Injectivity Audit on Functions \(f(A) = f(B)\): Applying \(f\) to both sides of an equation or inequality is an \(\iff\) only on a domain where \(f\) is strictly monotone/injective. When squaring, attach the sign guard \(B \ge 0\).
  3. Domain Preservation Audit (Logarithms, Radicals, Trig): When combining \(\ln A + \ln B \mapsto \ln(AB)\) or \(\tan\alpha + \tan\beta\), explicitly carry forward the original domain restrictions \(A > 0,\; B > 0\) (or \(\alpha, \beta \neq \frac{\pi}{2} + k\pi\)).
  4. Explicit Two-Way Inverse for Bijections: When proving \(|X| = |Y|\) via a map \(\Phi : X \to Y\), define the backward map \(\Psi : Y \to X\) explicitly and verify that \(\Psi(\Phi(x)) = x\) for all \(x \in X\) and \(\Phi(\Psi(y)) = y\) for all \(y \in Y\).

Box P78.B · Three-Key Recognition Diagnosis

  • Claim type: Solving an equation with radicals, logarithms, absolute values, or fractions; proving an algebraic inequality; or proving that two combinatorial sets have equal cardinality (\(|X| = |Y|\)).
  • Problem shape: Multi-step chains \(S_0 \iff S_1 \iff \cdots \iff S_m\) where non-injective steps (squaring), variable multipliers (clearing denominators), or domain shifts (\(\ln A + \ln B = \ln(AB)\)) appear.
  • Tools at hand: Guarded equivalences, sign analysis on factors, completing the square (P04), and involution/bijection construction.

4 · Worked exemplars

Exemplar 1 (Equations & Inequalities with Guards) · Logarithmic domain shifts and radical inequalities

Problem. Solve over the real numbers \(x \in \mathbb{R}\) using chains of guarded equivalences (\(\iff\)):

  1. The logarithmic equation \(\log_2(x - 1) + \log_2(x - 3) = 3\).
  2. The radical inequality \(\sqrt{x + 3} < x - 3\).

Solution.

Part 1 (Guarding the logarithmic domain contraction). In \(\log_2(x - 1) + \log_2(x - 3)\), both arguments must be strictly positive: \(x - 1 > 0\) and \(x - 3 > 0\), whose intersection is \(x > 3\). If you merge the logs into \(\log_2\bigl((x-1)(x-3)\bigr) = 3\) without recording \(x > 3\), the product \((x-1)(x-3) = 8\) is also positive when both factors are negative (\(x < 1\)), spawning the ghost root \(x = -1\)! Carrying the guard \(x > 3\) makes every step an exact equivalence:

\[ \begin{aligned} \log_2(x - 1) + \log_2(x - 3) = 3 &\quad\Longleftrightarrow\quad \Bigl(x - 1 > 0,\;\; x - 3 > 0,\;\;\text{and}\;\; \log_2\bigl((x - 1)(x - 3)\bigr) = 3\Bigr) \\ &\quad\Longleftrightarrow\quad \Bigl(x > 3 \;\;\text{and}\;\; x^2 - 4x - 5 = 0\Bigr) \\ &\quad\Longleftrightarrow\quad \Bigl(x > 3 \;\;\text{and}\;\; (x - 5)(x + 1) = 0\Bigr) \quad\Longleftrightarrow\quad x = 5. \end{aligned} \]

Part 2 (Guarding a radical inequality). For \(\sqrt{A} < B\) to hold over \(\mathbb{R}\), the radicand \(A\) must be nonnegative (\(A \ge 0\)), the upper bound \(B\) must be strictly positive (since \(0 \le \sqrt{A} < B \implies B > 0\)), and on \(0 \le \sqrt{A} < B\) squaring is strictly increasing (\(A < B^2\)). Applying Rule 2 of Fig P78.1 with \(A = x + 3\) and \(B = x - 3\) gives

\[ \begin{aligned} \sqrt{x + 3} < x - 3 &\quad\Longleftrightarrow\quad \Bigl(x + 3 \ge 0,\;\; x - 3 > 0,\;\;\text{and}\;\; x + 3 < (x - 3)^2\Bigr) \\ &\quad\Longleftrightarrow\quad \Bigl(x > 3 \;\;\text{and}\;\; x^2 - 7x + 6 > 0\Bigr) \\ &\quad\Longleftrightarrow\quad \Bigl(x > 3 \;\;\text{and}\;\; (x - 6)(x - 1) > 0\Bigr) \quad\Longleftrightarrow\quad x > 6. \end{aligned} \]

Notice that without the guard \(x > 3\), the quadratic \((x - 6)(x - 1) > 0\) would falsely accept every \(x \in [-3, 1)\) (for example \(x = -2\), where \(\sqrt{1} = +1 \not< -5\))!

Exemplar 2 (Bidirectional Inequality Chains) · Proving the HM–GM–AM–QM inequality chain and its equality condition in one pass

Problem. For any two positive real numbers \(a, b > 0\), prove the four-mean inequality chain (Harmonic \(\le\) Geometric \(\le\) Arithmetic \(\le\) Quadratic Mean)

\[ \frac{2}{\frac{1}{a} + \frac{1}{b}} \;\le\; \sqrt{ab} \;\le\; \frac{a + b}{2} \;\le\; \sqrt{\frac{a^2 + b^2}{2}}, \]

and prove that equality holds in each link if and only if \(a = b\).

Solution.

Because \(a > 0\) and \(b > 0\), every mean above is strictly positive, so squaring (\(0 < X \le Y \iff X^2 \le Y^2\)) and multiplying by \(2 > 0\) or \(a + b > 0\) are unconditional equivalences (\(\iff\)) (P04):

  • AM \(\le\) QM: \[ \frac{a + b}{2} \;\le\; \sqrt{\frac{a^2 + b^2}{2}} \;\;\Longleftrightarrow\;\; \frac{(a + b)^2}{4} \;\le\; \frac{a^2 + b^2}{2} \;\;\Longleftrightarrow\;\; a^2 + 2ab + b^2 \;\le\; 2a^2 + 2b^2 \;\;\Longleftrightarrow\;\; (a - b)^2 \;\ge\; 0. \]
  • GM \(\le\) AM: \[ \sqrt{ab} \;\le\; \frac{a + b}{2} \;\;\Longleftrightarrow\;\; 4ab \;\le\; (a + b)^2 \;\;\Longleftrightarrow\;\; 0 \;\le\; a^2 - 2ab + b^2 \;\;\Longleftrightarrow\;\; (a - b)^2 \;\ge\; 0. \]
  • HM \(\le\) GM: Since \(\frac{2}{1/a + 1/b} = \frac{2ab}{a + b}\) and \(\sqrt{ab} > 0\), dividing by \(\sqrt{ab} > 0\) gives \[ \frac{2ab}{a + b} \;\le\; \sqrt{ab} \;\;\Longleftrightarrow\;\; 2\sqrt{ab} \;\le\; a + b \;\;\Longleftrightarrow\;\; \sqrt{ab} \;\le\; \frac{a + b}{2} \;\;\Longleftrightarrow\;\; (a - b)^2 \;\ge\; 0. \]

Because every single arrow in all three chains is \(\iff\), and \((a - b)^2 \ge 0\) holds for all \(a, b \in \mathbb{R}\) with equality if and only if \(a = b\), both the inequalities and their exact equality conditions are proved in one stroke!

Exemplar 3 (Reversible Combinatorics) · Glaisher's explicit two-way bijection for Euler's partition theorem

Problem. In P73 · Generating functions (Exemplar 3), we proved via infinite products that the number of partitions of \(n\) into odd parts equals the number of partitions of \(n\) into distinct parts. Construct an explicit, step-by-step reversible bijection \(\Phi : \mathcal{O}_n \leftrightarrow \mathcal{D}_n\) between the two sets of partitions and trace both directions on \(n = 10\).

Solution.

Step 1 (Forward map \(\Phi : \text{Odd parts} \to \text{Distinct parts}\) via binary grouping). Take any partition of \(n\) into odd parts: suppose each odd integer \(m \in \{1, 3, 5, \dots\}\) appears \(c_m \ge 0\) times, so \(n = \sum_{m \text{ odd}} c_m \cdot m\). Write each multiplicity \(c_m > 0\) in its unique binary expansion (P73, Exercise P73.4): \(c_m = 2^{r_1} + 2^{r_2} + \cdots + 2^{r_k}\) with \(0 \le r_1 < r_2 < \cdots < r_k\). Replace the \(c_m\) copies of \(m\) by the parts

\[ 2^{r_1} m, \;\; 2^{r_2} m, \;\; \dots, \;\; 2^{r_k} m. \]

Why are all resulting parts across all odd \(m\) distinct? Because by the Fundamental Theorem of Arithmetic, every positive integer \(d\) factors uniquely as \(d = 2^r \cdot m\) where \(m\) is its odd part and \(2^r\) is the highest power of \(2\) dividing \(d\)!

Step 2 (Inverse map \(\Psi : \text{Distinct parts} \to \text{Odd parts}\) via repeated halving). Given any partition of \(n\) into distinct parts \(d_1 > d_2 > \cdots > d_s\), factor each part as \(d_j = 2^{r_j} m_j\) (with \(m_j\) odd) and split \(d_j\) into \(2^{r_j}\) copies of the odd number \(m_j\) (equivalently, repeatedly split every even part \(2k \mapsto k + k\) until all parts are odd!). Because binary expansion and prime-power factorization \(d = 2^r m\) are both unique, \(\Psi(\Phi(\lambda)) = \lambda\) and \(\Phi(\Psi(\mu)) = \mu\) (illustrated for \(n = 10\) in Fig P78.3, right).

5 · When the trick breaks

Exhibit A — Dividing by an expression \(E(x)\) that can equal zero: the "\(2 = 1\)" fallacy and lost roots. In the classic bogus proof that \(2 = 1\), one starts with \(a = b > 0\), multiplies by \(a\) and subtracts \(b^2\) to get \(a^2 - b^2 = ab - b^2\), factors as \((a - b)(a + b) = b(a - b)\), and divides by \(a - b\) to conclude \(a + b = b \implies 2b = b \implies 2 = 1\)! The fatal step is dividing by \(E = a - b = 0\). In genuine algebra, dividing \((x - 3)(x - 1) = 2(x - 3)\) by \(x - 3\) commits the same error in reverse: it throws away the valid solution \(x = 3\)!

Mitigation: Never divide an equation by a variable expression \(E(x)\); instead, subtract everything to one side, factor out \(E(x)\), and apply Rule 3 of Fig P78.1: \(E(x)\bigl(A(x) - B(x)\bigr) = 0 \iff \bigl(E(x) = 0 \text{ or } A(x) = B(x)\bigr)\).

Price: Carrying an OR branch \(E(x) = 0\).

Default: Factor rather than cancel whenever a common term contains the unknown \(x\).

Exhibit B — Multiplying an inequality by a denominator \(D(x)\) of unknown sign. In \(\frac{x + 1}{x - 2} < 3\) (Fig P78.3, left), multiplying both sides by \(x - 2\) without a sign guard silently assumes \(x - 2 > 0\), losing every solution with \(x < 2\)! Why? Because when \(x - 2 < 0\), multiplying by \(x - 2\) reverses the inequality sign from \(<\) to \(>\).

Mitigation: Never cross-multiply an inequality by an expression \(D(x)\) of variable sign. Instead, either move all terms to one side (\(\frac{A(x)}{D(x)} - C < 0\)) and analyze the sign table of numerator and denominator, or multiply both sides by the strictly positive square \(D(x)^2 > 0\) (with the guard \(D(x) \neq 0\)):

\[ \frac{N(x)}{D(x)} < 0 \quad\Longleftrightarrow\quad N(x) \cdot D(x) < 0. \]

Price: Factoring a single product \(N(x) D(x) < 0\).

Default: Replace division \(\frac{N(x)}{D(x)} < 0\) with multiplication \(N(x)D(x) < 0\)!

Exhibit C — One-way combinatorial maps: defining \(\Phi : X \to Y\) without checking surjectivity or injectivity. Suppose a student claims that the map \(\Phi\) sending a graph on \(n\) vertices to its degree sequence \((d_1, \dots, d_n)\) proves that two graph families have the same size. Without an inverse map \(\Psi\), \(\Phi\) can be many-to-one (two non-isomorphic graphs can share the same degree sequence) or fail to hit all of \(Y\)!

Mitigation: Always write down the explicit backward map \(\Psi : Y \to X\) and verify both \(\Psi(\Phi(x)) = x\) and \(\Phi(\Psi(y)) = y\) (Obligation 4 of Box P78.A).

Price: Defining the reverse decoding rule \(\Psi\).

Default: A bijection proof is only half-finished until the inverse map \(\Psi\) is written down and checked.

Honest scope of this chapter. In logic and algebra, making every step reversible is the passage from preorders (\(\implies\)) to equivalence relations (\(\iff\)) and groupoids/isomorphisms (P16). In computer science and physics, reversible computing (Landauer's Principle, 1961; Bennett's reversible Turing machines, 1973; and unitary quantum gates \(U^\dagger U = I\)) proves that any irreversible step that erases a bit of information (like \(x \mapsto x^2\) erasing the sign of \(x\)) must dissipate at least \(k_B T \ln 2\) of thermodynamic heat, whereas reversible bijective steps can in principle be executed with zero entropy production!

7 · Lineage interlude

From Viète and Descartes's equation transformations to Dedekind–Cantor bijections and Landauer–Bennett reversible computing (1591 – 1980).

  • François Viète (1591) & René Descartes (1637): Developing symbolic algebra, Viète and Descartes studied how root sets transform under substitutions \(x \mapsto x + c\) and \(x \mapsto x^2\), observing that squaring introduces "false" (negative) roots alongside "true" (positive) roots unless sign conditions are tracked.
  • Georg Cantor (1878) & Richard Dedekind (1888): To define when two infinite sets \(X\) and \(Y\) have the same cardinality without counting to a final integer, Cantor and Dedekind elevated the reversible bijection (\(\Phi : X \to Y\) with two-sided inverse \(\Psi = \Phi^{-1}\)) to the foundational definition of equinumerosity across all of mathematics.
  • James Whitbread Lee Glaisher (1883) & Major Percy MacMahon (1915): Dissatisfied with purely formal power-series proofs of partition identities, Glaisher and his successors initiated bijective combinatorics — demanding explicit, step-by-step reversible algorithms (such as binary merging vs. halving in Exemplar 3) that explain why two finite sets have the same size.
  • Rolf Landauer (1961), Charles H. Bennett (1973) & Tommaso Toffoli (1980): Landauer discovered that logically irreversible operations (such as an AND gate \((a, b) \mapsto a \wedge b\) that erases its inputs) must dissipate at least \(k_B T \ln 2\) of heat per erased bit. Bennett and Toffoli proved that any computation can be made 100% logically reversible by keeping auxiliary history/guard bits (such as the \(3\)-bit Toffoli gate in Exercise P78.5) — laying the gate-level foundation for quantum computing!

8 · Exercises

Exercise P78.1 (●○○ — Banishing a ghost root with a guarded radical equivalence). Solve the real equation

\[ \sqrt{x + 7} + x \;=\; 5 \qquad (x \in \mathbb{R}) \]

by isolating the square root and writing a single chain of guarded equivalences (\(\iff\)). Explain which root of the resulting quadratic is rejected by the guard and why it appeared.

Hint

Subtract \(x\) first to get \(\sqrt{x + 7} = 5 - x\), then apply \(\sqrt{A} = B \iff (B \ge 0 \text{ and } A = B^2)\).

Worked answer

1. Guarded equivalence chain. Isolating the radical and applying Rule 1 of Fig P78.1 gives

\[ \begin{aligned} \sqrt{x + 7} + x = 5 &\quad\Longleftrightarrow\quad \sqrt{x + 7} = 5 - x \\ &\quad\Longleftrightarrow\quad \Bigl(5 - x \ge 0 \;\;\text{and}\;\; x + 7 = (5 - x)^2\Bigr) \\ &\quad\Longleftrightarrow\quad \Bigl(x \le 5 \;\;\text{and}\;\; x^2 - 11x + 18 = 0\Bigr) \\ &\quad\Longleftrightarrow\quad \Bigl(x \le 5 \;\;\text{and}\;\; (x - 2)(x - 9) = 0\Bigr) \quad\Longleftrightarrow\quad x = 2. \end{aligned} \]

2. Origin of the rejected root \(x = 9\). The guard \(x \le 5\) rejects \(x = 9\), because at \(x = 9\) the right-hand side is \(5 - 9 = -4 < 0\), so \(x = 9\) solves the opposite-branch equation \(-\sqrt{9 + 7} = 5 - 9\) (\(-4 = -4\)), not \(+\sqrt{9 + 7} = 5 - 9\) (\(+4 \neq -4\)).

Exercise P78.2 (●●○ — The two-branch guarded equivalence for \(\sqrt{A} > B\)). In Exemplar 1, we saw that \(\sqrt{A} < B \iff (A \ge 0,\; B > 0,\; A < B^2)\). Now consider the opposite inequality \(\sqrt{A} > B\) over \(\mathbb{R}\).

  1. Explain why \(\sqrt{A} > B\) is automatically true whenever \(A \ge 0\) and \(B < 0\) (without squaring!), and write down the complete two-branch guarded equivalence for \(\sqrt{A} > B\).
  2. Use your guarded equivalence to solve \(\sqrt{x + 2} > x\) over \(\mathbb{R}\).
Hint

Split into \(B < 0\) (where \(\sqrt{A} \ge 0 > B\) holds as long as the square root is defined, \(A \ge 0\)) and \(B \ge 0\) (where both sides are nonnegative, so \(\sqrt{A} > B \iff A > B^2\)).

Worked answer

1. Complete guarded equivalence for \(\sqrt{A} > B\). When \(B < 0\) and \(A \ge 0\), the left-hand side is nonnegative (\(\sqrt{A} \ge 0\)) while the right-hand side is negative (\(B < 0\)), so \(\sqrt{A} > B\) holds unconditionally (whereas squaring could reverse the inequality!). When \(B \ge 0\), squaring is strictly increasing on \([0, \infty)\), and \(A > B^2 \ge 0\) automatically implies \(A \ge 0\). Thus:

\[ \sqrt{A} > B \quad\Longleftrightarrow\quad \Bigl(A \ge 0 \;\;\text{and}\;\; B < 0\Bigr) \;\;\text{OR}\;\; \Bigl(B \ge 0 \;\;\text{and}\;\; A > B^2\Bigr). \]

2. Solving \(\sqrt{x + 2} > x\). Applying the two-branch equivalence with \(A = x + 2\) and \(B = x\):

  • Branch 1 (\(B < 0\)): \(x + 2 \ge 0 \text{ and } x < 0 \;\Longleftrightarrow\; x \in [-2, 0)\).
  • Branch 2 (\(B \ge 0\)): \(x \ge 0 \text{ and } x + 2 > x^2 \;\Longleftrightarrow\; x \ge 0 \text{ and } (x - 2)(x + 1) < 0 \;\Longleftrightarrow\; x \in [0, 2)\).

Taking the union of the two branches gives the exact solution interval \([-2, 0) \cup [0, 2) = [-2, 2)\).

Exercise P78.3 (●●● — Stars-and-bars as an explicit two-way reversible bijection). Let \(X\) be the set of ordered \(k\)-tuples of nonnegative integers \(\mathbf{x} = (x_1, x_2, \dots, x_k) \in \mathbb{Z}_{\ge 0}^k\) such that \(x_1 + x_2 + \cdots + x_k = n\), and let \(Y\) be the set of \((k-1)\)-element subsets \(S = \{s_1 < s_2 < \cdots < s_{k-1}\} \subseteq \{1, 2, \dots, n + k - 1\}\). Define the forward map \(\Phi : X \to Y\) by

\[ s_j \;:=\; j \,+\, \sum_{i=1}^j x_i \qquad (j = 1, 2, \dots, k - 1). \]
  1. Prove that \(1 \le s_1 < s_2 < \cdots < s_{k-1} \le n + k - 1\) for every \(\mathbf{x} \in X\).
  2. Write down the explicit inverse formula \(\Psi : Y \to X\) recovering \((x_1, \dots, x_k)\) from \((s_1, \dots, s_{k-1})\), and verify algebraically that \(\Psi(\Phi(\mathbf{x})) = \mathbf{x}\) and \(\Phi(\Psi(S)) = S\).
Hint

Notice that \(s_j - s_{j-1} = 1 + x_j \ge 1\) because \(x_j \ge 0\)! To invert, solve for \(x_j\) in terms of \(s_j - s_{j-1}\) (P69).

Worked answer

1. Image lands inside \(Y\). Since \(x_i \ge 0\), we have \(s_1 = 1 + x_1 \ge 1\), for each \(2 \le j \le k-1\) we have \(s_j - s_{j-1} = 1 + x_j \ge 1 \implies s_{j-1} < s_j\), and \(s_{k-1} = (k - 1) + \sum_{i=1}^{k-1} x_i = (k - 1) + (n - x_k) \le n + k - 1\). Thus \(\Phi(\mathbf{x}) \in Y\).

2. Explicit inverse \(\Psi\) and two-way verification. Set \(s_0 := 0\) and \(s_k := n + k\). Define \(\Psi(s_1, \dots, s_{k-1}) = (x_1, \dots, x_k)\) by

\[ x_j \;:=\; s_j - s_{j-1} - 1 \qquad (j = 1, 2, \dots, k). \]

Because \(s_{j-1} < s_j\) are integers, \(s_j - s_{j-1} \ge 1 \implies x_j \ge 0\), and by telescoping (P69),

\[ \sum_{j=1}^k x_j \;=\; \sum_{j=1}^k \bigl(s_j - s_{j-1} - 1\bigr) \;=\; (s_k - s_0) - k \;=\; (n + k - 0) - k \;=\; n. \]

Checking \(\Psi(\Phi(\mathbf{x}))\): \((j + \sum_{i=1}^j x_i) - (j - 1 + \sum_{i=1}^{j-1} x_i) - 1 = x_j\). Checking \(\Phi(\Psi(S))\): \(j + \sum_{i=1}^j (s_i - s_{i-1} - 1) = j + (s_j - s_0) - j = s_j\). Thus \(\Phi\) and \(\Psi\) are exact two-sided inverses, proving \(|X| = |Y| = \binom{n+k-1}{k-1}\).

Exercise P78.4 (◆ — Pattern-unknown diagnosis). A student attempts to solve the real inequality

\[ \frac{x^2 - 3x + 2}{x^2 - 3x - 4} \;\le\; 1 \]

by writing: "Multiply both sides by \(x^2 - 3x - 4\) to obtain \(x^2 - 3x + 2 \le x^2 - 3x - 4\); subtract \(x^2 - 3x\) from both sides to get \(2 \le -4\), which is impossible; therefore there are no real solutions." Diagnose the exact reversibility violation in the student's argument, and solve the inequality correctly using a chain of guarded equivalences (\(\iff\)).

Worked answer

1. Pattern diagnosis (P78 · Make every step reversible, Exhibit B). The student multiplied an inequality by the variable denominator \(D(x) = x^2 - 3x - 4 = (x - 4)(x + 1)\) without checking its sign! That step is valid with \(\le\) only when \(D(x) > 0\). When \(D(x) < 0\) (which occurs on the interval \(x \in (-1, 4)\)), multiplying by \(D(x) < 0\) reverses \(\le\) to \(\ge\), turning \(2 \le -4\) (false) into \(2 \ge -4\) (always true!) — so the student threw away the entire solution interval!

2. Reversible solution via subtraction of \(1\). Subtracting \(1\) from both sides is an unconditional equivalence that preserves the denominator and its sign:

\[ \begin{aligned} \frac{x^2 - 3x + 2}{x^2 - 3x - 4} \le 1 &\quad\Longleftrightarrow\quad \frac{(x^2 - 3x + 2) - (x^2 - 3x - 4)}{x^2 - 3x - 4} \le 0 \\ &\quad\Longleftrightarrow\quad \frac{6}{(x - 4)(x + 1)} \le 0 \\ &\quad\Longleftrightarrow\quad (x - 4)(x + 1) < 0 \quad (\text{since } 6 > 0 \text{ cannot equal } 0) \\ &\quad\Longleftrightarrow\quad -1 < x < 4. \end{aligned} \]

Thus the exact solution set is the open interval \((-1, 4)\).

Exercise P78.5 (◐ — Exploration: Reversible computing and the \(3\)-bit Toffoli gate). In classical digital logic, the \(2\)-bit AND gate \((a, b) \mapsto a \wedge b\) (for \(a, b \in \{0, 1\}\)) is irreversible: if the output is \(0\), you cannot tell whether the input \((a, b)\) was \((0, 0)\), \((0, 1)\), or \((1, 0)\). In 1980, Tommaso Toffoli showed how to make AND completely reversible by adding a third "target/ancilla" bit \(c \in \{0, 1\}\) and defining the \(3\)-bit Toffoli gate \(T : \{0, 1\}^3 \to \{0, 1\}^3\) (where \(\oplus\) denotes addition modulo \(2\), i.e., XOR):

\[ T(a, b, c) \;:=\; \bigl(a,\;\; b,\;\; c \oplus (a \cdot b)\bigr). \]
  1. Prove algebraically using \(x \oplus x = 0\) in \(\mathbb{Z}_2\) that the Toffoli gate is its own inverse: \(T\bigl(T(a, b, c)\bigr) = (a, b, c)\) for all \(2^3 = 8\) bit triples \((a, b, c) \in \{0, 1\}^3\)!
  2. Show how choosing special values of \((a, b, c)\) allows the single reversible gate \(T\) to simulate the universal irreversible gates AND (\(a \cdot b\)), NOT (\(\neg a = 1 \oplus a\)), and XOR (\(a \oplus c\)) without ever losing information!
Hint

Apply \(T\) a second time to \((a, b, c \oplus ab)\): the first two bits are still \(a\) and \(b\), so the third bit becomes \((c \oplus ab) \oplus ab\). For AND, set \(c = 0\); for NOT, set \(b = 1, c = 1\); for XOR, set \(b = 1\).

Worked answer

1. Self-inverse property (\(T \circ T = \operatorname{Id}\)). Because \(T\) leaves the two control bits \(a, b\) untouched, applying \(T\) twice adds \(a \cdot b \pmod 2\) to the third bit twice:

\[ T\bigl(T(a, b, c)\bigr) \;=\; T\bigl(a,\; b,\; c \oplus ab\bigr) \;=\; \bigl(a,\; b,\; (c \oplus ab) \oplus ab\bigr) \;=\; \bigl(a,\; b,\; c \oplus (ab \oplus ab)\bigr) \;=\; (a, b, c), \]

since \(x \oplus x = 0\) in modulo-\(2\) arithmetic! Thus \(T\) is a permutation (bijection) of the \(8\) states \(\{0, 1\}^3\).

2. Universal irreversible logic embedded inside a reversible bijection.

  • AND gate: Initialize the ancilla bit to \(c = 0\): \(T(a, b, 0) = (a, b, a \cdot b)\). Carrying the inputs \((a, b)\) alongside the output \(a \cdot b\) is the exact hardware analog of carrying the guard \(G(x)\) in Box P78!
  • NOT gate: Fix \(b = 1\) and \(c = 1\): \(T(a, 1, 1) = (a, 1, 1 \oplus a) = (a, 1, \neg a)\).
  • XOR gate: Fix \(b = 1\): \(T(a, 1, c) = (a, 1, c \oplus a)\).
