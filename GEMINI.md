# AGENTS.md — agent entry point

Any AI agent continuing work on this repo starts here.

1. Read `README.md` — organization overview + where we are.
2. Read `records/pattern-map.md` (the chapter skeleton). Read `records/authoring-rules.md` before authoring anything — it is binding.
3. The book lives in `book/`; `book/index.html` is the status board — keep it in sync with every publication.
4. Records are lean (owner directive 2026-11-02): no session logs, no page logs, no receipt ledgers. Historical records are in this repo's git history only. Never rewrite published pages.
5. Verify pushes by fetch-back; check returned paths (status "added" on an existing file = drift).
6. Publishing (visibility / Pages) is a user gate.
